# TW Results website (twresults.com) — v2 redesign, 18/10/2026

Static HTML/CSS with a little JavaScript. No framework, no third-party calls except the form service and GA4 (after consent). Font: Arimo, self-hosted (`assets/fonts`, 17 KB).

## Pages
`/` Home · `/what-we-do/` · `/results/` (Eaton Embroidery client case study) · `/about-dan/` · `/contact/` · `/privacy/` · `404.html`

v3 (18/10/2026, after G Bot review): honest case study (work first, "held #2" proof line), no checkbox on the form, "trades and local businesses", rotating "barber near me" example, phone flag, first-person voice, Backlinko stat linked and described as organic results, service-area schema (no address), FAQ schema identical to the visible FAQ.

v2 (18/10/2026): shorter copy, enquiry form in the home hero (Formspree, `_gotcha` spam trap, on-page thank-you), "You: page 2" map illustration, keyword-led titles `[Service] [City] | TW Results`, ProfessionalService + FAQPage + BreadcrumbList schema. `python3 _build/wordcount.py` prints words per page. Eaton Embroidery is a client case study only: never describe it as Dan's company or "our group".

All pages are generated by `_build/build.py` (shared header, footer, schema). Edit the copy there, then run it. Don't hand-edit the HTML.

```
python3 _build/build.py          # PREVIEW build (what's in this repo now)
python3 _build/build.py --live   # LAUNCH build
```

## THIS IS A PREVIEW BUILD — before launch on twresults.com
The preview lives at https://darohx.github.io/twresults-preview/ and must not be indexed. Before launch:
1. **Remove `<meta name="robots" content="noindex, nofollow">`** from every page, and
2. **Replace the Disallow-all `robots.txt`** with the allow-all version (Googlebot, GPTBot, ClaudeBot, PerplexityBot + sitemap line).
3. Set the `404.html` `<base href>` from `/twresults-preview/` to `/`.

`python3 _build/build.py --live` does all three. Then add a `CNAME` file containing `twresults.com` (this preview repo deliberately has none).
