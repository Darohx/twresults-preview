## THIS IS A PREVIEW BUILD — before launch on twresults.com
The preview lives at https://darohx.github.io/twresults-preview/ and must not be indexed. Before launch:
1. **Remove `<meta name="robots" content="noindex, nofollow">`** from every page, and
2. **Replace the Disallow-all `robots.txt`** with the allow-all version (Googlebot, GPTBot, ClaudeBot, PerplexityBot + sitemap line).
3. Set the `404.html` `<base href>` from `/twresults-preview/` to `/`.

`python3 _build/build.py --live` does all three. Then add a `CNAME` file containing `twresults.com` (this preview repo deliberately has none).

## Adding a town or city page (template ready, none published yet)

Town pages are built by `area_page()` in `_build/build.py` and live at `/areas/<slug>/`. Each one gets its own title (default "Local SEO in <Town> | TW Results"), meta description, H1 ("Local SEO and websites in <Town>"), breadcrumb (Home > Town, with BreadcrumbList schema), a Service schema with `areaServed` set to that town, the services list and the enquiry form.

To add one:
1. In `_build/build.py`, add an entry to `AREA_PAGES`, for example
   `{"name": "Chellaston", "slug": "chellaston", "desc": "<unique meta, under 155 characters>", "intro": "<1 to 2 true sentences about this town>", "local": ["<specific local point>", "..."]}`.
   `"title"` is optional (keep it under 60 characters). The build stops if `desc` or `intro` is missing.
2. Write unique text for every town. Don't copy one town's text to another (Google treats that as doorway pages).
3. Run `python3 _build/build.py` (preview) or `--live`. The page is created, added to `sitemap.xml` automatically, and if `name` matches a town in `TOWNS`, that town in the home page's "Areas I cover" list becomes a link to it.

Positioning: Derby-first SEO (home title, Derby in the H1 support line, the towns in `areaServed`), plus `REACH` = "Derby, the East Midlands and UK-wide" and `REACH_LINE` ("Based in Derby. Working across the East Midlands and UK-wide.") used in the support line, footer, areas section and contact page. `areaServed` also lists East Midlands (AdministrativeArea) and United Kingdom (Country).


Town list: not shown on any page since v9. The towns live only in `TOWNS` (schema `areaServed`). If town pages are published later, `towns_li("../")` renders a linked list again; add it to the Contact page at the same time.
